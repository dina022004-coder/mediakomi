# Медиакоми 🏠

Мобильная игра по реальным объявлениям о продаже квартир в Республике Коми (г. Инта, Авито).

Игроку по очереди показывают фотографии квартир из активных объявлений. Нужно ползунком выбрать цену, которая кажется правильной, и нажать «Оценить». После этого показывается реальная цена, разница, начисленные баллы и ссылка на настоящее объявление. В раунде — 10 квартир, в конце — итоговый результат и «психологический портрет» игрока.

## Архетипы по итогам игры

| Архетип | Когда достаётся |
|---|---|
| 🏡 Адекватный квартирант | ставки в целом совпадают с реальными ценами |
| 🧠 Жадный студент | ставки систематически ниже реальных цен |
| 💸 Транжира | ставки систематически выше реальных цен |

## Балльная система

Отклонение ставки от реальной цены: ≤5% — 100 баллов, ≤10% — 80, ≤20% — 60, ≤35% — 40, ≤50% — 20, больше — 0. Максимум за раунд — 1000.

## Запуск

Статический сайт без сборки: просто откройте `index.html` или положите папку на любой статический хостинг.

## Публикация на GitHub Pages

1. Создайте репозиторий и загрузите содержимое этой папки:
   ```bash
   git init && git add -A && git commit -m "Медиакоми"
   git remote add origin https://github.com/<user>/<repo>.git
   git push -u origin main
   ```
2. В настройках репозитория: **Settings → Pages → Source: Deploy from a branch → main / (root) → Save**.
3. Через минуту игра будет доступна по адресу `https://<user>.github.io/<repo>/`.

Файл `.nojekyll` уже добавлен — GitHub Pages отдаст статику как есть.

## Структура

```
index.html      — разметка (3 экрана: старт, лот, итоги)
style.css       — стиль в фирменном цвете ВШЭ #012D6E, mobile-first
app.js          — логика игры: галерея, слайдер, баллы, архетипы
data.js         — лоты (сгенерирован скриптом build_data.py)
img/            — оптимизированные фото объявлений (~10 КБ каждое)
build_data.py   — скрипт: парсит CSV, скачивает фото, генерирует data.js
```

## Обновление данных

Положите свежий CSV объявлений и запустите:

```bash
python3 -I build_data.py
```

Скрипт скачает только фото активных лотов (без фото лоты пропускаются) и пересоберёт `data.js`.
